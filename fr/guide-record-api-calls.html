Comment enregistrer les requêtes HTTPS (appels d’API) d’un site web

Pour voir les appels d’API d’une page, ouvrez les DevTools de votre navigateur, choisissez Network et filtrez sur Fetch/XHR (XHR dans Firefox) ; rien à installer. Pour les garder, faire signaler ceux qui posent problème, et les rejouer ou les exporter, utilisez une extension de navigateur comme RequestFox : installez-la, ouvrez le site, appuyez sur « Démarrer l’enregistrement » (ou Alt Shift S) et utilisez le site comme d’habitude. Chaque fetch, XMLHttpRequest, trame WebSocket et événement envoyé par le serveur apparaît dans la liste dès qu’il commence.

Pour RequestFox 2.5.0, vérifié le 19 novembre 2026.

D’abord, l’outil intégré : le panneau Network des DevTools

Pas besoin d’extension pour voir les appels d’API d’une page. Dans Chrome, ouvrez les DevTools (F12), choisissez Network et cliquez sur le filtre Fetch/XHR. Faites un clic droit sur une requête et choisissez Copy pour la copier en cURL ou en fetch, et cochez Preserve log pour garder les requêtes d’un chargement de page à l’autre [1]. Dans Firefox, le Moniteur réseau s’ouvre avec Ctrl+Maj+E (Cmd+Opt+E sur Mac) [2] ; son bouton XHR filtre la liste, et « Copier comme cURL » et « Copier comme Fetch » sont dans le menu du clic droit [3].

Les DevTools listent tout en direct mais vous laissent juger, et la liste disparaît quand vous les fermez. RequestFox ajoute les signalements, l’historique et l’export. RequestFox ou le panneau Network des DevTools.

Étapes pour enregistrer les appels d’API dans Chrome, Edge ou Firefox

  1. Installez RequestFox

    Ajoutez-le depuis le Chrome Web Store ou les Modules complémentaires de Firefox. Aucune inscription.

  2. Ouvrez le site à tester

    N’importe quelle page web normale convient. Les pages du navigateur, comme celle des extensions, un nouvel onglet ou le Web Store, ne peuvent pas être enregistrées ; RequestFox vous le dit si vous essayez.

  3. Appuyez sur « Démarrer l’enregistrement »

    Cliquez sur l’icône RequestFox pour ouvrir le panneau latéral (la barre latérale dans Firefox) et appuyez sur Démarrer l’enregistrement, ou appuyez sur Alt+Maj+S (Option+Maj+S sur Mac). La première fois, le navigateur vous demande d’autoriser l’accès au site : autorisez-le.

  4. Utilisez le site comme d’habitude

    Parcourez le flux que vous testez. Chaque appel apparaît dès qu’il commence, rattaché au clic ou à l’envoi de formulaire qui l’a causé. Pour ne pas manquer les tout premiers appels d’une page (connexion, configuration, feature flags), cochez « Recharger la page pour enregistrer ses appels de démarrage » avant d’appuyer sur Démarrer l’enregistrement.

  5. Lisez les signalements

    Les appels qui ont échoué, qui ont été lents, qui sont partis deux fois ou qui ont cassé dans un 200 OK sont signalés. Ouvrez-en un pour voir ses en-têtes, son corps, sa chronologie et la raison en mots simples.

  6. Arrêtez, et gardez les preuves

    Appuyez sur Arrêter. La session est gardée dans Historique pour la rouvrir et la comparer. Avec Exporter, vous l’enregistrez en rapport HTML, HAR, CSV ou JSON, ou vous copiez un appel sous forme de code.

Trouver un appel dans un long enregistrement

Tapez dans le champ de recherche. Chaque mot doit correspondre, dans n’importe quel ordre, et les filtres resserrent la liste :

  • status:500 ou method:POST
  • host:api.example.com, ou -host:cdn.example.com pour écarter un hôte
  • path:/users/:id pour chaque appel à un même endpoint, quel que soit l’id

Si rien n’apparaît

  • La liste dit d’ouvrir d’abord un site : vous avez appuyé sur « Démarrer l’enregistrement » sur une page du navigateur. Ouvrez le site, puis appuyez sur « Démarrer l’enregistrement ».
  • Vous avez choisi de ne pas autoriser l’accès : appuyez de nouveau sur « Démarrer l’enregistrement » et autorisez-le. Vous pourrez retirer cet accès plus tard dans les paramètres de l’extension de votre navigateur.
  • La liste est vide pendant l’enregistrement : la page n’a encore fait aucun appel. Cliquez sur quelque chose qui charge des données, ou rechargez la page.
  • Le raccourci ne fait rien : une autre extension l’utilise peut-être. Définissez-le à nouveau sur chrome://extensions/shortcuts (Firefox : about:addons, la roue dentée, Gérer les raccourcis d’extensions).
