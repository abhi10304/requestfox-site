A Postman alternative with no login

RequestFox is a browser extension for Chrome and Firefox with no account to make, no sign-in and no server of ours: install it and send a request. It is free with no paid tier. Insomnia's Scratch Pad is another local-only way to work without logging in [2]. This page says what each vendor's own pricing page states about price and accounts, and where it says nothing.

Facts about other tools are from their own pricing pages, checked 20 November 2026; sources below. Written by the RequestFox team, for RequestFox 2.5.0.

What do the other tools' pages say?

  • Postman: Free is "for individuals", with one user [1]. Whether you can use the apps without signing in is not on the pricing page, so read its account documentation before you rely on it.
  • Insomnia: the pricing page describes a "local-only, free forever Scratch Pad" you can use without logging in. Its Essentials plan is free and includes Git Sync for up to 3 users and 1,000 mock server requests a month [2].
  • Thunder Client: the Free plan caps a collection at 50 requests and leaves out Git Sync, custom scripting and data-driven testing, which start at Starter [3].
  • Bruno: the Open Source plan is $0 and includes the API client, testing, scripting, code generation and unlimited collection runs. Its pricing page says nothing about accounts [4].

What is RequestFox, and what is it not?

RequestFox sits in your browser beside the page you are testing. It records the calls the page makes, flags the ones that failed, were slow or repeated, and lets you send, edit, mock and export them. It is free, with no paid tier, and nothing is sent to us. See RequestFox vs Postman for the full comparison.

It is not a team workspace: there is no cloud sync, by design, so you share work as files (collections, sessions, HAR and reports). It sees what a browser tab sends, not a phone or desktop app. If your team needs shared workspaces, one of the tools above is the better fit.

How do I start without logging in?

  1. Add RequestFox from the Chrome Web Store or Firefox Add-ons. There is no sign-up step.
  2. Press Compose in the top bar, type an address, and press Send.
  3. Already have a collection? In Compose open Import and press Import a collection…: Postman, Insomnia, Bruno, Hoppscotch and Thunder Client exports and HAR files are read. How to import a Postman collection.
