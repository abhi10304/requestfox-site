كيف تسجّل طلبات HTTPS (استدعاءات API) التي يرسلها موقع ويب

لترى طلبات API التي ترسلها صفحة، افتح أدوات المطوّرين في متصفحك، واختر Network وصفِّ على Fetch/XHR (XHR في Firefox)؛ لا شيء لتثبيته. ولتحتفظ بها، وتُعلَّم الطلبات المعطوبة، وتعيد إرسالها أو تصدّرها، استخدم إضافة متصفح مثل RequestFox: ثبّتها، وافتح الموقع، واضغط «بدء التسجيل» (أو Alt Shift S)، واستخدم الموقع كالمعتاد. يظهر كل fetch وXMLHttpRequest وإطار WebSocket وحدث يرسله الخادم في القائمة لحظة بدئه.

لإصدار RequestFox 2.5.0، رُوجع في 19 نوفمبر 2026.

أولًا، الطريقة المدمجة: لوحة Network في أدوات المطوّرين

لا تحتاج إلى إضافة لترى طلبات API في صفحة. في Chrome، افتح أدوات المطوّرين (F12)، واختر Network، وانقر مرشّح Fetch/XHR. انقر بزر الفأرة الأيمن على طلب واختر Copy لتنسخه كـ cURL أو fetch، وفعّل Preserve log لتبقى الطلبات بعد إعادة تحميل الصفحة [1]. وفي Firefox، يُفتح مراقب الشبكة بـ Ctrl+Shift+E (وCmd+Opt+E على Mac) [2]؛ وزرّ XHR فيه يصفّي القائمة، و«نسخ كـ cURL» و«نسخ كـ Fetch» في قائمة النقر الأيمن [3].

تعرض أدوات المطوّرين كل شيء مباشرةً لكنها تترك الحكم لك، وتختفي القائمة حين تغلقها. ويضيف RequestFox العلامات وسجل الجلسات والتصدير. RequestFox مقابل لوحة Network في أدوات المطوّرين.

خطوات تسجيل طلبات API في Chrome أو Firefox

  1. ثبّت RequestFox

    أضفه من سوق Chrome الإلكتروني أو إضافات Firefox. لا تسجيل في أي شيء.

  2. افتح الموقع الذي تريد اختباره

    تصلح أي صفحة ويب عادية. أما صفحات المتصفح نفسه، مثل صفحة الإضافات أو علامة تبويب جديدة أو السوق الإلكتروني، فلا يمكن تسجيلها؛ ويخبرك RequestFox بذلك إن حاولت.

  3. اضغط «بدء التسجيل»

    انقر أيقونة RequestFox لفتح اللوحة الجانبية (الشريط الجانبي في Firefox) واضغط بدء التسجيل، أو اضغط Alt+Shift+S (وOption+Shift+S على Mac). في المرة الأولى يطلب منك المتصفح السماح بالوصول إلى الموقع: اسمح به.

  4. استخدم الموقع كالمعتاد

    انقر عبر المسار الذي تختبره. يظهر كل طلب لحظة بدئه، مرتبطًا بالنقرة أو إرسال النموذج الذي تسبب فيه. وكي لا تفوتك أولى طلبات الصفحة (تسجيل الدخول، الإعدادات، مفاتيح الميزات)، فعّل «إعادة تحميل الصفحة لتسجيل طلبات البدء» قبل أن تضغط بدء التسجيل.

  5. اقرأ العلامات

    تُعلَّم الطلبات التي فشلت أو أبطأت أو أُرسلت مرتين أو تعطّلت داخل استجابة 200 OK. افتح أحدها لترى ترويساته ومحتواه وتوقيته والسبب بكلمات بسيطة.

  6. أوقف، واحتفظ بالدليل

    اضغط إيقاف. تُحفظ الجلسة في سجل الجلسات لتعيد فتحها وتقارنها. وبـ تصدير تحفظها تقريرًا بصيغة HTML أو HAR أو CSV أو JSON، أو تنسخ طلبًا واحدًا ككود.

العثور على طلب واحد في تسجيل طويل

اكتب في مربع البحث. يجب أن تطابق كل كلمة، بأي ترتيب، وعوامل التصفية تضيّق القائمة:

  • status:500 أو method:POST
  • host:api.example.com، أو -host:cdn.example.com لاستبعاد مضيف
  • path:/users/:id لكل طلب إلى نقطة نهاية واحدة، أيًّا كان المعرّف

إن لم يظهر شيء

  • تطلب منك القائمة فتح موقع أولًا: ضغطت «بدء التسجيل» في صفحة من صفحات المتصفح. افتح الموقع، ثم اضغط «بدء التسجيل».
  • اخترت عدم السماح بالوصول: اضغط «بدء التسجيل» مجددًا واسمح به. يمكنك إلغاء الوصول لاحقًا من إعدادات الإضافة في متصفحك.
  • القائمة فارغة أثناء التسجيل: لم ترسل الصفحة أي طلب بعد. انقر شيئًا يحمّل بيانات، أو أعد تحميل الصفحة.
  • الاختصار لا يفعل شيئًا: ربما تستخدمه إضافة أخرى. عيّنه من جديد في chrome://extensions/shortcuts (Firefox: about:addons، ثم الترس، ثم إدارة اختصارات الإضافات).
