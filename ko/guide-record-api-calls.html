웹사이트가 보내는 HTTPS 요청(API 호출)을 기록하는 방법

페이지의 API 호출을 보려면 브라우저의 DevTools를 열고 '네트워크'(Network) 패널을 고른 뒤 Fetch/XHR(Firefox에서는 XHR)로 거르세요. 설치할 것은 없습니다. 호출을 보관하고, 문제 있는 호출에 플래그를 받고, 다시 보내거나 내보내려면 RequestFox 같은 브라우저 확장 프로그램을 쓰세요. 설치하고 사이트를 연 다음 '기록 시작'(또는 Alt Shift S)을 누르고 평소처럼 사이트를 쓰면 됩니다. 모든 fetch, XMLHttpRequest, WebSocket 프레임, 서버 전송 이벤트가 시작되는 순간 목록에 나타납니다.

먼저 기본 제공 방법: DevTools의 Network 패널

페이지의 API 호출을 보는 데는 확장 프로그램이 필요 없습니다. Chrome에서 DevTools(F12)를 열고 '네트워크'(Network) 패널을 고른 뒤 Fetch/XHR 필터를 클릭하세요. 요청을 마우스 오른쪽 버튼으로 클릭하고 '복사'(Copy)를 고르면 cURL이나 fetch로 복사할 수 있고, '로그 보존'(Preserve log)을 켜면 페이지를 다시 불러와도 요청이 남습니다 [1]. Firefox에서는 네트워크 모니터가 Ctrl+Shift+E(Mac에서는 Cmd+Opt+E)로 열립니다 [2]. XHR 버튼으로 목록을 거를 수 있고, 'cURL로 복사'와 'Fetch로 복사'는 오른쪽 클릭 메뉴에 있습니다 [3].

DevTools는 모든 것을 실시간으로 보여 주지만 판단은 사용자에게 맡기고, 닫으면 목록이 사라집니다. RequestFox는 플래그, 내역, 내보내기를 더합니다. RequestFox와 DevTools Network 패널 비교.

Chrome 또는 Firefox에서 API 호출을 기록하는 단계

  1. RequestFox 설치하기

    Chrome 웹 스토어 또는 Firefox 부가 기능에서 추가하세요. 가입할 것은 없습니다.

  2. 테스트할 사이트 열기

    일반 웹 페이지라면 어디서나 됩니다. 확장 프로그램 페이지, 새 탭, 웹 스토어 같은 브라우저 자체 페이지는 기록할 수 없으며, 시도하면 RequestFox가 알려 줍니다.

  3. '기록 시작' 누르기

    RequestFox 아이콘을 클릭해 사이드 패널(Firefox에서는 사이드바)을 열고 기록 시작을 누르거나 Alt+Shift+S(Mac에서는 Option+Shift+S)를 누르세요. 처음에는 브라우저가 사이트 접근을 허용할지 묻습니다. 허용하세요.

  4. 평소처럼 사이트 사용하기

    테스트하는 흐름을 클릭해 나가세요. 각 호출은 시작되는 순간 나타나며, 그것을 일으킨 클릭이나 폼 제출과 연결됩니다. 페이지의 맨 처음 호출(로그인, 설정, 기능 플래그)까지 놓치지 않으려면 기록 시작을 누르기 전에 '시작 시 호출도 기록하도록 페이지 새로고침'을 켜세요.

  5. 플래그 읽기

    실패했거나, 느렸거나, 두 번 나갔거나, 200 OK 안에서 고장 난 호출에는 표시가 붙습니다. 하나를 열면 헤더, 본문, 타이밍, 그리고 이유를 쉬운 말로 볼 수 있습니다.

  6. 중지하고 증거 남기기

    중지를 누르세요. 세션은 내역에 보관되어 다시 열고 비교할 수 있습니다. 내보내기로 HTML 보고서, HAR, CSV, JSON으로 저장하거나 호출 하나를 코드로 복사하세요.

긴 기록에서 호출 하나 찾기

검색 상자에 입력하세요. 각 단어가 순서와 상관없이 모두 맞아야 하며, 필터로 목록을 좁힐 수 있습니다:

  • status:500 또는 method:POST
  • host:api.example.com, 또는 호스트를 빼려면 -host:cdn.example.com
  • path:/users/:id: id와 상관없이 한 엔드포인트로 가는 모든 호출

아무것도 나타나지 않으면

  • 목록이 먼저 사이트를 열라고 합니다: 브라우저 페이지에서 '기록 시작'을 눌렀습니다. 사이트를 연 다음 '기록 시작'을 누르세요.
  • 접근을 허용하지 않았습니다: '기록 시작'을 다시 누르고 허용하세요. 나중에 브라우저의 확장 프로그램 설정에서 접근을 취소할 수 있습니다.
  • 기록 중인데 목록이 비어 있습니다: 페이지가 아직 호출을 보내지 않았습니다. 데이터를 불러오는 무언가를 클릭하거나 페이지를 새로고침하세요.
  • 단축키가 동작하지 않습니다: 다른 확장 프로그램이 쓰고 있을 수 있습니다. chrome://extensions/shortcuts에서 다시 지정하세요(Firefox: about:addons, 톱니바퀴, 확장 기능 단축키 관리).
