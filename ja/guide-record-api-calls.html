Web サイトが行う HTTPS リクエスト（API 呼び出し）を記録する方法

ページの API 呼び出しを見るだけなら、ブラウザーの DevTools を開き、「ネットワーク」（Network）パネルを選んで Fetch/XHR（Firefox では XHR）で絞り込みます。インストールは不要です。呼び出しを残し、問題のあるものにフラグを付け、リプレイやエクスポートをしたいなら、RequestFox のようなブラウザー拡張機能を使います。インストールしてサイトを開き、「記録を開始」（または Alt Shift S）を押して、いつもどおりサイトを使ってください。fetch、XMLHttpRequest、WebSocket のフレーム、サーバー送信イベントは、始まった瞬間に一覧に表示されます。

まずは標準の方法：DevTools の Network パネル

ページの API 呼び出しを見るだけなら拡張機能は要りません。Chrome では DevTools（F12）を開き、「ネットワーク」（Network）パネルを選んで Fetch/XHR フィルターをクリックします。リクエストを右クリックして「コピー」（Copy）を選ぶと cURL や fetch としてコピーでき、「ログを保持」（Preserve log）をオンにするとページを読み込み直してもリクエストが残ります [1]。Firefox ではネットワークモニターが Ctrl+Shift+E（Mac では Cmd+Opt+E）で開きます [2]。XHR ボタンで一覧を絞り込め、「cURL としてコピー」と「Fetch としてコピー」は右クリックメニューにあります [3]。

DevTools はすべてをリアルタイムで一覧にしますが、判断はあなた任せで、閉じると一覧は消えます。RequestFox はフラグ、履歴、エクスポートを加えます。RequestFox と DevTools の Network パネルの比較。

Chrome や Firefox で API 呼び出しを記録する手順

  1. RequestFox をインストールする

    Chrome ウェブストアまたは Firefox Add-ons から追加します。登録は一切不要です。

  2. テストしたいサイトを開く

    普通の Web ページならどれでも使えます。拡張機能のページ、新しいタブ、ウェブストアなどブラウザー自身のページは記録できません。試すと RequestFox がそう伝えます。

  3. 「記録を開始」を押す

    RequestFox のアイコンをクリックしてサイドパネル（Firefox ではサイドバー）を開き、記録を開始 を押すか、Alt+Shift+S（Mac では Option+Shift+S）を押します。初回はブラウザーがサイトへのアクセスの許可を求めるので、許可してください。

  4. いつもどおりサイトを使う

    テストしたい流れをクリックして進めます。各呼び出しは始まった時点で表示され、それを起こしたクリックやフォーム送信に結び付けられます。ページの最初期の呼び出し（サインイン、設定、フィーチャーフラグ）も逃さないよう、記録を開始 を押す前に「ページを再読み込みして起動時の通信も記録」をオンにしてください。

  5. フラグを読む

    失敗した、遅かった、2 回送られた、200 OK の中で壊れていた呼び出しには印が付きます。開くと、ヘッダー、本文、タイミング、そして理由が平易な言葉で表示されます。

  6. 停止して、証拠を残す

    停止 を押します。セッションは 履歴 に保存され、あとで開き直して比べられます。エクスポート で HTML レポート、HAR、CSV、JSON として保存するか、1 件の呼び出しをコードとしてコピーできます。

長い記録から 1 件の呼び出しを探す

検索ボックスに入力します。各語はどの順番でも一致する必要があり、フィルターで一覧を絞り込めます：

  • status:500 または method:POST
  • host:api.example.com、またはホストを除外する -host:cdn.example.com
  • path:/users/:id：id に関係なく、1 つのエンドポイントへのすべての呼び出し

何も表示されないとき

  • 一覧に「まずサイトを開いてください」と出る：ブラウザーのページで「記録を開始」を押しました。サイトを開いてから「記録を開始」を押してください。
  • アクセスを許可しなかった：もう一度「記録を開始」を押して許可してください。アクセスはあとでブラウザーの拡張機能の設定から取り消せます。
  • 記録中なのに一覧が空：ページがまだ呼び出しをしていません。データを読み込む操作をするか、ページを再読み込みしてください。
  • ショートカットが効かない：別の拡張機能が使っているかもしれません。chrome://extensions/shortcuts で設定し直してください（Firefox：about:addons、歯車アイコン、拡張機能のショートカットキーの管理）。
