How to copy a request as cURL, and convert a cURL command to code

In Chrome or Firefox, right-click a request in the Network panel and choose Copy, then Copy as cURL [1][2]. To turn that command into Python, JavaScript, Go or another language, paste it into RequestFox, a browser extension for Chrome and Firefox: in Compose open Import and press Paste a curl command…, then use More, Copy as code…, and pick the language. RequestFox copies any request as code in 15 languages, and it keeps real tokens out of what it copies unless you ask.

For RequestFox 2.5.0, checked 19 November 2026. Facts about browsers are from their own documentation, checked 20 November 2026; sources below.

How do I copy a request as cURL in Chrome or Firefox?

  • Chrome: in the DevTools Network panel, right-click the request under Name, hover over Copy and choose Copy as cURL. Copy as fetch is next to it [1].
  • Firefox: in the Network Monitor, right-click the request and choose Copy, then Copy as cURL [2].

The command holds the request's headers, which can include cookies and tokens. Keep it private until you have checked it.

How do I convert a cURL command to Python, fetch or Go?

  1. Paste the command

    In RequestFox press Compose, open Import and press Paste a curl command…. Paste it into the box and confirm. The status line says Filled from the cURL command. The method, address, headers and body are now in the request. Form fields that sent a file are left out, and a note says which.

  2. Check it, and send it if you like

    Press Send to see the response. It also works as a way to check that the command still does what you meant.

  3. Open Copy as code

    Open the request's More menu and choose Copy as code….

  4. Pick the language and copy

    Choose a Language and press Copy. The choices are cURL for bash and for Windows cmd, PowerShell, JavaScript (fetch), Node.js (fetch), Python (requests), HTTPie, Go (net/http), Java (HttpClient), C# (HttpClient), PHP (cURL), Ruby (Net::HTTP), Swift (URLSession), Kotlin (OkHttp) and Rust (reqwest).

If the box says it does not look like a curl command, the text has to start with curl.

Can I copy a call I recorded as cURL or code?

Yes, with no browser menu to find. Open the call's card, then More: Copy as cURL copies it as a command, and Copy as code… opens the same language list. How to record API calls shows how a call gets there.

Will a token end up in the code I copy?

Not by default. While Hide passwords, tokens and card numbers in what is recorded is on in Settings, hidden values show as ***REDACTED*** in the copied code, and a note tells you to put the real ones in. A secret that came from an environment is kept as a variable, with a note to set its value before you run the code. If you need the real values, Use the real URL and headers shows them, with a warning that the code holds live secrets and should not be shared.
