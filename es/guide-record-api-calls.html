Cómo grabar las solicitudes HTTPS (llamadas a la API) que hace un sitio web

Para ver las llamadas a la API que hace una página, abre las DevTools de tu navegador, elige Red (Network) y filtra por Fetch/XHR (XHR en Firefox); no hay nada que instalar. Para conservarlas, que se marquen las que fallan y poder repetirlas o exportarlas, usa una extensión del navegador como RequestFox: instálala, abre el sitio, pulsa «Iniciar grabación» (o Alt Shift S) y usa el sitio como siempre. Cada fetch, XMLHttpRequest, trama de WebSocket y evento enviado por el servidor aparece en la lista en cuanto empieza.

Para RequestFox 2.5.0, revisado el 19 de noviembre de 2026.

Primero, lo que ya trae el navegador: el panel Red de DevTools

No necesitas una extensión para ver las llamadas a la API de una página. En Chrome, abre DevTools (F12), elige Red (Network) y haz clic en el filtro Fetch/XHR. Haz clic derecho en una solicitud y elige Copiar (Copy) para copiarla como cURL o como fetch, y marca Conservar registro (Preserve log) para conservar las solicitudes entre cargas de página [1]. En Firefox, el Monitor de red se abre con Ctrl+Shift+E (Cmd+Opt+E en un Mac) [2]; su botón XHR filtra la lista, y Copiar como cURL y Copiar como Fetch están en el menú del clic derecho [3].

DevTools lo lista todo en directo pero te deja a ti el juicio, y la lista desaparece al cerrarlo. RequestFox añade las marcas, el historial y la exportación. RequestFox frente al panel Red de DevTools.

Pasos para grabar las llamadas a la API en Chrome o Firefox

  1. Instala RequestFox

    Añádelo desde la Chrome Web Store o desde Complementos de Firefox. No hay que registrarse en nada.

  2. Abre el sitio que quieres probar

    Sirve cualquier página web normal. Las páginas propias del navegador, como la de extensiones, una pestaña nueva o la Web Store, no se pueden grabar; RequestFox te lo dice si lo intentas.

  3. Pulsa «Iniciar grabación»

    Haz clic en el icono de RequestFox para abrir el panel lateral (la barra lateral en Firefox) y pulsa Iniciar grabación, o pulsa Alt+Shift+S (Option+Shift+S en un Mac). La primera vez, el navegador te pide permitir el acceso al sitio: permítelo.

  4. Usa el sitio como siempre

    Recorre el flujo que estás probando. Cada llamada aparece al empezar, ligada al clic o al envío de formulario que la causó. Para no perderte las primeras llamadas de una página (inicio de sesión, configuración, feature flags), marca «Recargar la página para grabar sus llamadas de inicio» antes de pulsar Iniciar grabación.

  5. Lee las marcas

    Se marcan las llamadas que fallaron, fueron lentas, se enviaron dos veces o se rompieron dentro de un 200 OK. Abre una para ver sus cabeceras, su cuerpo, sus tiempos y el motivo en palabras sencillas.

  6. Detén la grabación y guarda la evidencia

    Pulsa Detener. La sesión se guarda en el Historial para volver a abrirla y compararla. Con Exportar la guardas como informe HTML, HAR, CSV o JSON, y también puedes copiar una llamada como código.

Encontrar una llamada en una grabación larga

Escribe en el cuadro de búsqueda. Cada palabra tiene que coincidir, en cualquier orden, y los filtros acotan la lista:

  • status:500 o method:POST
  • host:api.example.com, o -host:cdn.example.com para dejar fuera un host
  • path:/users/:id para cada llamada a un mismo endpoint, sea cual sea el id

Si no aparece nada

  • La lista dice que abras primero un sitio: pulsaste «Iniciar grabación» en una página del navegador. Abre el sitio y pulsa «Iniciar grabación».
  • Elegiste no permitir el acceso: pulsa «Iniciar grabación» otra vez y permítelo. Puedes quitar el acceso más tarde en la configuración de la extensión en tu navegador.
  • La lista está vacía mientras grabas: la página aún no ha hecho ninguna llamada. Haz clic en algo que cargue datos, o recarga la página.
  • El atajo no hace nada: puede que otra extensión lo use. Vuelve a asignarlo en chrome://extensions/shortcuts (Firefox: about:addons, el engranaje, Gestionar atajos de extensiones).
