कोई वेबसाइट जो HTTPS रिक्वेस्ट (API कॉल) करती है, उन्हें कैसे रिकॉर्ड करें

किसी पेज की API कॉल देखने के लिए अपने ब्राउज़र का DevTools खोलें, Network चुनें और Fetch/XHR (Firefox में XHR) पर फ़िल्टर करें; कुछ इंस्टॉल नहीं करना। उन्हें रखने, गड़बड़ वाली कॉल फ़्लैग करवाने और उन्हें फिर से भेजने या एक्सपोर्ट करने के लिए RequestFox जैसा ब्राउज़र एक्सटेंशन इस्तेमाल करें: इसे इंस्टॉल करें, साइट खोलें, “रिकॉर्डिंग शुरू करें” दबाएँ (या Alt Shift S) और साइट को हमेशा की तरह इस्तेमाल करें। हर fetch, XMLHttpRequest, WebSocket फ़्रेम और सर्वर-सेंट इवेंट शुरू होते ही सूची में आ जाता है।

पहले, ब्राउज़र का अपना तरीका: DevTools का Network पैनल

किसी पेज की API कॉल देखने के लिए एक्सटेंशन की ज़रूरत नहीं है। Chrome में DevTools (F12) खोलें, Network चुनें और Fetch/XHR फ़िल्टर पर क्लिक करें। किसी request पर राइट-क्लिक करके Copy चुनें और उसे cURL या fetch के रूप में कॉपी करें, और पेज लोड के बीच request रखने के लिए Preserve log पर टिक करें [1]। Firefox में Network Monitor, Ctrl+Shift+E (Mac पर Cmd+Opt+E) से खुलता है [2]; उसका XHR बटन सूची फ़िल्टर करता है, और Copy as cURL और Copy as Fetch राइट-क्लिक मेन्यू में हैं [3]।

DevTools सब कुछ लाइव दिखाता है पर परखना आप पर छोड़ता है, और बंद करते ही सूची चली जाती है। RequestFox फ़्लैग, हिस्ट्री और एक्सपोर्ट जोड़ता है। RequestFox बनाम DevTools का Network पैनल।

Chrome या Firefox में API कॉल रिकॉर्ड करने के चरण

  1. RequestFox इंस्टॉल करें

    इसे Chrome Web Store या Firefox Add-ons से जोड़ें। किसी चीज़ के लिए साइन अप नहीं करना।

  2. वह साइट खोलें जिसे आप टेस्ट करना चाहते हैं

    कोई भी सामान्य वेब पेज चलेगा। ब्राउज़र के अपने पेज, जैसे एक्सटेंशन पेज, नया टैब या Web Store, रिकॉर्ड नहीं किए जा सकते; कोशिश करने पर RequestFox यह बता देता है।

  3. “रिकॉर्डिंग शुरू करें” दबाएँ

    साइड पैनल (Firefox में साइडबार) खोलने के लिए RequestFox आइकन पर क्लिक करें और रिकॉर्डिंग शुरू करें दबाएँ, या Alt+Shift+S दबाएँ (Mac पर Option+Shift+S)। पहली बार ब्राउज़र साइट का एक्सेस देने को कहता है: अनुमति दें।

  4. साइट को हमेशा की तरह इस्तेमाल करें

    जिस फ़्लो को आप टेस्ट कर रहे हैं, उसमें क्लिक करते जाएँ। हर कॉल शुरू होते ही दिखती है, उस क्लिक या फ़ॉर्म सबमिट से जुड़ी हुई जिससे वह हुई। किसी पेज की बिल्कुल शुरुआती कॉल (साइन-इन, कॉन्फ़िग, फ़ीचर फ़्लैग) न छूटें, इसके लिए रिकॉर्डिंग शुरू करें दबाने से पहले “शुरुआती कॉल रिकॉर्ड करने के लिए पेज रीलोड करें” पर टिक करें।

  5. फ़्लैग पढ़ें

    जो कॉल फ़ेल हुईं, धीमी रहीं, दो बार गईं या 200 OK के अंदर टूटीं, उन पर निशान लगता है। किसी एक को खोलकर उसके header, body, टाइमिंग और कारण को सीधे शब्दों में देखें।

  6. रोकें, और सबूत रखें

    रोकें दबाएँ। सेशन फिर से खोलने और तुलना के लिए हिस्ट्री में रखा जाता है। एक्सपोर्ट से इसे HTML रिपोर्ट, HAR, CSV या JSON के रूप में सेव करें, या किसी एक कॉल को कोड के रूप में कॉपी करें।

लंबी रिकॉर्डिंग में एक कॉल ढूँढें

खोज बॉक्स में लिखें। हर शब्द का मेल खाना ज़रूरी है, किसी भी क्रम में, और फ़िल्टर सूची को छोटा करते हैं:

  • status:500 या method:POST
  • host:api.example.com, या किसी होस्ट को बाहर रखने के लिए -host:cdn.example.com
  • path:/users/:id, किसी एक एंडपॉइंट की हर कॉल के लिए, id चाहे जो हो

अगर कुछ न दिखे

  • सूची कहती है कि पहले कोई साइट खोलें: आपने ब्राउज़र के किसी पेज पर “रिकॉर्डिंग शुरू करें” दबाया। साइट खोलें, फिर “रिकॉर्डिंग शुरू करें” दबाएँ।
  • आपने एक्सेस न देने का चुनाव किया: फिर से “रिकॉर्डिंग शुरू करें” दबाएँ और अनुमति दें। बाद में आप अपने ब्राउज़र की एक्सटेंशन सेटिंग्स में यह एक्सेस हटा सकते हैं।
  • रिकॉर्डिंग के दौरान सूची खाली है: पेज ने अभी तक कोई कॉल नहीं की है। डेटा लोड करने वाली किसी चीज़ पर क्लिक करें, या पेज रीलोड करें।
  • शॉर्टकट कुछ नहीं करता: हो सकता है कोई दूसरा एक्सटेंशन उसे इस्तेमाल कर रहा हो। उसे chrome://extensions/shortcuts पर फिर से सेट करें (Firefox: about:addons, गियर, Manage Extension Shortcuts)।
