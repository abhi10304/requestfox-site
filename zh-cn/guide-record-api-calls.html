如何录制网站发出的 HTTPS 请求（API 调用）

要查看页面发出的 API 调用，打开浏览器的 DevTools，选择“网络”（Network）面板，并筛选 Fetch/XHR（Firefox 中为 XHR），无需安装任何东西。若要保留这些调用、让有问题的调用被标记出来，并重放或导出它们，请使用 RequestFox 这样的浏览器扩展：安装它，打开网站，按“开始录制”（或 Alt Shift S），然后照常使用网站。每个 fetch、XMLHttpRequest、WebSocket 帧和服务器发送事件一开始就会出现在列表中。

适用于 RequestFox 2.5.0，核对于 2026年11月19日。

先看浏览器自带的方法：DevTools 的 Network 面板

查看页面的 API 调用并不需要扩展。在 Chrome 中，打开 DevTools（F12），选择“网络”（Network）面板，点击 Fetch/XHR 筛选。右键点击一个请求并选择“复制”（Copy），可把它复制为 cURL 或 fetch；勾选“保留日志”（Preserve log） 可在页面重新加载后保留请求 [1]。在 Firefox 中，网络监视器用 Ctrl+Shift+E 打开（Mac 上为 Cmd+Opt+E）[2]；它的 XHR 按钮可筛选列表，“复制为 cURL”和“复制为 Fetch”在右键菜单中 [3]。

DevTools 会实时列出一切，但判断留给你，而且关闭后列表就没了。RequestFox 增加了标记、历史和导出。RequestFox 与 DevTools 的 Network 面板对比。

在 Chrome 或 Firefox 中录制 API 调用的步骤

  1. 安装 RequestFox

    从 Chrome 应用商店或 Firefox 附加组件添加。无需注册任何东西。

  2. 打开你要测试的网站

    任何普通网页都可以。浏览器自己的页面，例如扩展程序页、新标签页或应用商店，无法录制；如果你尝试，RequestFox 会告诉你。

  3. 按“开始录制”

    点击 RequestFox 图标打开侧边栏（Firefox 中也是侧边栏），然后按开始录制，或按 Alt+Shift+S（Mac 上为 Option+Shift+S）。第一次时，浏览器会请你允许访问该网站：请允许。

  4. 照常使用网站

    把你要测试的流程点一遍。每个调用一开始就会出现，并关联到引发它的点击或表单提交。为了不漏掉页面最早的调用（登录、配置、功能开关），请在按开始录制之前勾选“重新加载页面以录制启动时的调用”。

  5. 阅读标记

    失败、缓慢、发了两次或在 200 OK 里出错的调用都会被标记。打开其中一个，就能看到它的请求头、请求体、耗时，以及用大白话写的原因。

  6. 停止，并保留证据

    按停止。会话会保存在历史中，方便重新打开和对比。用导出把它保存为 HTML 报告、HAR、CSV 或 JSON，或把单个调用复制为代码。

在很长的录制中找到一个调用

在搜索框中输入。每个词都必须匹配，顺序不限，筛选条件可以缩小列表：

  • status:500 或 method:POST
  • host:api.example.com，或用 -host:cdn.example.com 排除某个主机
  • path:/users/:id：某个端点的每次调用，无论 id 是什么

如果什么都没出现

  • 列表提示先打开一个网站：你是在浏览器自己的页面上按的“开始录制”。打开网站，再按“开始录制”。
  • 你选择了不允许访问：再按一次“开始录制”并允许。以后可以在浏览器的扩展设置中撤销这项访问权限。
  • 录制时列表为空：页面还没有发出任何调用。点击会加载数据的内容，或重新加载页面。
  • 快捷键没有反应：可能有别的扩展占用了它。在 chrome://extensions/shortcuts 重新设置（Firefox：about:addons，齿轮图标，管理扩展快捷键）。
