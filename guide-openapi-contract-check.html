Check API calls against an OpenAPI spec

RequestFox is a browser extension for Chrome, Edge and Firefox that checks the API calls your web app actually makes against your OpenAPI 3 or Swagger 2 spec. Import the spec and it's linked as the contract. Then record as usual: a call that breaks the spec shows “Spec mismatch” with the reason, a call the spec doesn't have shows “Not in spec”, and the Spec coverage line above the log counts how many operations you've covered. The same check runs in CI from the command line.

For RequestFox 2.5.0, checked 19 November 2026.

Steps

  1. Import the spec

    Import your OpenAPI 3 or Swagger 2 file, JSON or YAML. Every operation becomes a request you can send, and the spec is linked as the contract.

  2. Record the flow you test

    Press Start Recording and use the app. Calls to the spec's API are checked as they arrive. Calls to other sites, like analytics or fonts, are never judged.

  3. Read the marks

    “Spec mismatch” gives one line of reason, for example "response body $.price: expected number, got string". “Not in spec” marks a call the spec doesn't document. Details lists every problem.

  4. See what you have not covered

    Above the log you'll see "Spec coverage: 3 of 6 operations seen" (open Repeated problems if it's folded). Click it to list the operations you haven't called yet.

  5. Change or turn off the contract

    Settings → Mocks & rules → Pass/fail checks.

What is checked

Path, method and status must be in the spec, and the parameters, request body, content type, required response headers and response body must match it. Anything RequestFox can't check shows as "not checked", never as a pass.

The same check in CI

Export the session as JSON (or use a HAR file) and run the command-line tool against the spec. It prints one line per call and the coverage, and exits with 1 on a mismatch:

node requestfox-ci.mjs conform --spec openapi.yaml --session session.json --reporter junit --out results.xml

With --min-coverage 80 it also fails below that share of operations seen. How to get the command-line tool.
