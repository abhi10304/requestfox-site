Where RequestFox stands

Each of these API testing tools is the right pick for some job. Pick RequestFox when you're testing a web app and want its API problems found for you, the moment they happen.

Which tool for which job

  • Testing a web app and want problems found for you

    RequestFox. It records the calls as you click, flags what failed, dragged, fired twice or broke inside a 200 OK, and keeps every session.

  • A raw look at everything one page load does

    The DevTools Network panel. Built into the browser, and you do the filtering and reading. RequestFox vs DevTools

  • Designing, documenting and sharing APIs across a team

    Postman or Insomnia. RequestFox imports from both and exports back to both. RequestFox vs Postman · RequestFox vs Insomnia

  • Requests kept as plain files in Git, next to the code

    Bruno. In Chrome, RequestFox can keep a collection in a linked folder as files too. RequestFox vs Bruno

  • An open-source client on the web you can host yourself

    Hoppscotch. RequestFox has nothing to host: there's no server. RequestFox vs Hoppscotch

Where RequestFox falls short

  • It sees what a browser tab sends. Mobile and desktop apps need a proxy tool such as HTTP Toolkit, Proxyman or Charles.
  • There's no team workspace or cloud sync, by design. You share work as files: collections, sessions, HAR and reports.
  • Scripts run in Chrome only: Firefox doesn't let extensions run code typed at runtime.
  • No native gRPC or MQTT client (gRPC-Web and Connect only).

Every problem, named in plain words

Calls are judged as they finish. Pick a flag to read what the panel tells you about it.

Flag

POST /api/orders 500 412 ms

Why is this flagged?

The server failed while answering (a 5xx status).

What to do: Look at the server's logs for this moment; Replay sends the same request again to see if it repeats.

GET /api/search?q=boots 200 3.1 s

Why is this flagged?

The response took longer than your slow limit.

What to do: Timing in Details shows where the time went; the limit is in Settings.

POST /graphql 200 96 ms

Why is this flagged?

The response says the call failed, although its HTTP status is OK.

What to do: Read the error in the response: the status alone hides this failure.

GET /api/me 401 54 ms

Why is this flagged?

The call was refused and the token it sent had already expired.

What to do: Sign in again or refresh the token, then send the call again.

GET /api/cart 200 120 ms

Why is this flagged?

The response's shape (its fields and their types) is not what this call returned before.

What to do: Open the shape diff on the card to see what changed.

GET /api/stock/42 503 230 ms

Why is this flagged?

This call failed in some recorded sessions and passed in others.

What to do: Compare a failing and a passing response in History.

From the flag to the fix

01 Replay

Replay it, or edit it first

Send any recorded call again as it was, or change it in Compose. Environments, {{variables}}, OAuth 2.0 with device code, OAuth 1.0a, JWT Bearer and AWS Signature v4 are built in, and several requests can stay open at once.

Keep saved examples and notes on requests and collections. A cookie jar you switch on per site carries a sign-in to your next sends, and the WebSocket client has a Socket.IO mode.

How to replay and edit a request

02 Mock

Mock it, break it, slow it

Open a call and press Mock: its real status and body are there to change. Press Mock it, reload the page, and the page gets your response. A rule can also make a call fail, slow it down or pause it, without touching the backend. Rule sets and mock sets stay on when you want them to.

In Chrome you can also slow the whole tab, or rewrite a request or response with a script. Calls you changed carry a Mocked or Simulated label, so nobody mistakes them for real bugs.

How to mock an API response

03 Test

Check it, then run the same checks in CI

Add checks to an endpoint: status, time, fields, headers or a JSON Schema, and chain saved requests into suites. The downloadable command-line tool runs them in your pipeline and fails the build when a check fails. You also get advice on caching and compression, and a check that a response stays the same as last time.

Collections come in from Postman, Insomnia, Bruno, Hoppscotch and Thunder Client, OpenAPI 3, Swagger 2, WSDL, HAR and cURL. They go back out as Postman collections, collections for Bruno, Insomnia and Hoppscotch, OpenAPI 3.0, an API docs page, code in 15 languages, or Playwright, Cypress, k6, JMeter, Gatling and Locust scripts.

How to run your API checks in CI

04 AI tools

Test your AI tools, with no AI inside

RequestFox runs no AI model. It tests the AI tools you build: Compose connects to an MCP server and calls its tools, and a call to a language-model API shows the model, the token counts the response gives, the stop reason and the time.

With MCP control switched on (it's off by default), an AI agent on your own computer can record, replay and mock through RequestFox. Every send and replay waits for your click.

Questions

Is RequestFox free?

Yes. RequestFox is free, and our promise is written here: nothing you can use for free today will be put behind a paywall later. It has no ads, no account and no paid tier.

Does RequestFox send my data anywhere?

No. Everything RequestFox records stays in your browser's storage on your device. There is no RequestFox server, no analytics and no account. Authorization headers, cookies and secret-shaped fields are redacted by default in everything RequestFox keeps, logs or exports (Compose shows the response to your own request as it came; its Recent list keeps your last 100 sends, redacted, on this device until you press Clear), and site access is asked for only when you press Start, or, for the sites involved, when you send from Compose or run a test suite with nothing recording.

Does RequestFox use AI?

No. RequestFox runs no AI model. It can test the AI tools you build: MCP servers, and the calls a page makes to a language-model API. With MCP control switched on, which is off by default, an AI agent on your own computer can drive it, and every send waits for your click.

Is there a free Postman alternative that runs in the browser?

RequestFox is a free browser extension that composes and sends requests with environments, {{variables}}, auth helpers including OAuth 2.0 and saved collections, imports Postman, Insomnia, Bruno, Hoppscotch and Thunder Client collections, and exports Postman collections and collections for Bruno, Insomnia and Hoppscotch. Unlike a standalone client it also records the calls your web app really makes. It has no cloud workspace or team sync.

How is RequestFox different from the DevTools Network panel?

DevTools shows every request and leaves the judging to you. RequestFox flags failed, slow, duplicate and retried calls as they happen, ties each one to the click that caused it, checks your per-endpoint rules, and keeps every session so you can compare today's run with yesterday's. DevTools is better for a raw, live view of everything a page loads.
