A Postman Interceptor alternative: record your web app's API calls in the browser

Postman Interceptor is a browser extension that captures requests and cookies and hands them to Postman, so Postman has to be running (the desktop app) or open (the web app) [1]. RequestFox is another browser extension, for Chrome, Edge and Firefox. It records the calls a web app makes and flags the broken ones inside the browser, with no other app, and exports a Postman collection when you want the calls in Postman.

For RequestFox 2.5.0, checked 19 November 2026. Facts about Postman are from its own documentation, checked 4 November 2026; sources below. Written by the RequestFox team.

What does Postman Interceptor do, and what does it need?

Postman's documentation describes Interceptor as a companion to Postman that captures API traffic, including requests and cookies, from a web browser [1]. In short:

  • You start a capture session, use your browser, and stop it. The session then opens in Postman, where you can read its requests and cookies, and save the requests to a collection, grouped in folders by domain, by endpoint or both [1].
  • You can limit a capture by method and by domain or address, with regular expressions [1].
  • It can also sync cookies from the browser to the Postman cookie jar [1].
  • It needs Postman: the message "Interceptor disconnected" means the Postman desktop app is not running or the Postman web app is not open. Postman also asks that you are in an internal workspace where you can edit [1].
  • On Linux, and on older Postman versions for macOS and Windows, it needs a helper called Interceptor Bridge [1].
  • The extension is available for Chrome, Safari, Firefox and Edge [1].

Which one should I pick?

  • Interceptor fits when you already work in Postman and want captured calls to land in its collections, in a workspace you share, or need its cookie sync.
  • RequestFox fits when you are testing a web app and want the broken calls found for you, in the browser, with nothing else to run and no account.
  • You can use both. RequestFox imports and exports Postman collections, so a recording can end up in Postman. RequestFox vs Postman compares the two tools as a whole.

How do I record calls with RequestFox and open them in Postman?

  1. Record the calls in RequestFox

    Open the site, open RequestFox and press Start Recording (or Alt Shift S), then use the site as usual. Press Stop when you have the flow. How to record API calls.

  2. Export a Postman collection

    Press Export (bottom right) and choose Postman collection. The file is a Postman Collection v2.1. Postman's import page says its old v1 collection format is no longer supported [2].

  3. Import it in Postman

    In Postman, choose Use resources or import, open the Import tab and pick the file [2]. The collection appears in your sidebar.

What RequestFox records stays in your browser, and nothing is sent to us. The exported file goes where you put it. Interceptor passes what it captures to Postman, encrypted [1].

What does RequestFox not do?

  • It runs in Chrome, Edge and Firefox only.
  • It does not put recorded calls into a Postman workspace by itself: you export a file and import it.
  • It does not sync the browser's cookies to Postman. Cookie values are never exported or logged.
  • There is no team workspace or cloud sync. Share work as files, such as collections and reports.
  • It sees what a browser tab sends. Mobile and desktop apps need a proxy tool such as HTTP Toolkit, Proxyman or Charles.
