How to edit and resend a request in Chrome

Record the call with RequestFox, a browser extension for Chrome and Firefox, open its card and press Replay to send it again as it was, or choose Edit and send again… in its ··· menu to change the method, address, headers or body first. While recording, the request goes through the page, with its cookies and session. The browsers' own DevTools can do part of this: Chrome resends a request as an editable fetch() call in the Console, and Firefox has Edit and Resend.

For RequestFox 2.5.0, checked 19 November 2026.

Steps

  1. Record the call

    Press Start Recording in RequestFox and do what makes the call. How to record API calls.

  2. Open its card

    Click the call in the list. Search with filters such as method:POST or status:500 to find it fast.

  3. Press Replay to send it as it was

    The response shows on the card, for example "Replayed → 200 (134 ms)". The secrets redaction hides are still sent, because the replay uses the unredacted copy kept in memory.

  4. Or change it first: Edit and send again…

    In the card's ··· menu, choose Edit and send again…, change the method, address, headers or body, then press Send.

  5. Keep it for later

    Open in Compose, the next item in the same menu, turns it into a request you can save to a collection, use with environments and {{variables}}, and send again any time.

When the page's CORS rules block it

A replay normally runs as the page. If the API does not allow the page's origin, a GET, HEAD or OPTIONS replay is sent again from the extension by itself; other methods offer "Replay from the extension" first. Sent that way, a request has no page cookies and is marked From extension in the log.

Outside the browser

Copy as code gives you the same request in 15 languages, cURL for bash and Windows cmd included, plus PowerShell, fetch, Node.js, Python, HTTPie, Go, Java, C#, PHP, Ruby, Swift, Kotlin and Rust.

Can DevTools resend a request?

Yes, in both browsers, with a different shape. In Chrome, right-click a fetchable request in the Network panel and choose "Edit and resend as fetch". DevTools opens the Console drawer with the request filled in as a fetch() call; edit the call there and press Enter to send it [1]. In Firefox, the Headers tab of the Network Monitor has a Resend button with two items: Resend sends the request again, and Edit and Resend lets you change the method, URL, request headers or body, then Send [2].

What RequestFox adds: the response shows on the call's card and the call stays in the session History; a replay that the page's CORS rules block can be sent from the extension instead; and Open in Compose saves the request to a collection with environments and {{variables}}.
