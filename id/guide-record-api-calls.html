Cara merekam permintaan HTTPS (panggilan API) yang dibuat sebuah situs web

Untuk melihat panggilan API yang dibuat sebuah halaman, buka DevTools browser Anda, pilih panel Jaringan (Network), dan filter ke Fetch/XHR (XHR di Firefox); tidak ada yang perlu dipasang. Untuk menyimpannya, menandai yang bermasalah, dan mengirim ulang atau mengekspornya, gunakan ekstensi browser seperti RequestFox: pasang, buka situsnya, tekan “Mulai Merekam” (atau Alt Shift S), lalu gunakan situs seperti biasa. Setiap fetch, XMLHttpRequest, frame WebSocket, dan server-sent event masuk daftar begitu dimulai.

Untuk RequestFox 2.5.0, diperiksa pada 19 November 2026.

Pertama, cara bawaan: panel Network di DevTools

Anda tidak perlu ekstensi untuk melihat panggilan API sebuah halaman. Di Chrome, buka DevTools (F12), pilih panel Jaringan (Network), dan klik filter Fetch/XHR. Klik kanan sebuah permintaan dan pilih Salin (Copy) untuk menyalinnya sebagai cURL atau fetch, dan centang Pertahankan log (Preserve log) agar permintaan tetap ada antarmuat halaman [1]. Di Firefox, Network Monitor terbuka dengan Ctrl+Shift+E (Cmd+Opt+E di Mac) [2]; tombol XHR-nya memfilter daftar, dan Salin sebagai cURL serta Salin sebagai Fetch ada di menu klik kanan [3].

DevTools menampilkan semuanya secara langsung tetapi menyerahkan penilaian kepada Anda, dan daftarnya hilang saat Anda menutupnya. RequestFox menambahkan tanda, riwayat, dan ekspor. RequestFox dibanding panel Jaringan DevTools.

Langkah merekam panggilan API di Chrome, Edge atau Firefox

  1. Pasang RequestFox

    Tambahkan dari Chrome Web Store atau Firefox Add-ons. Tidak perlu mendaftar apa pun.

  2. Buka situs yang ingin Anda uji

    Halaman web biasa apa pun bisa. Halaman browser seperti halaman ekstensi, tab baru, atau Web Store tidak bisa direkam; RequestFox memberi tahu Anda jika Anda mencobanya.

  3. Tekan “Mulai Merekam”

    Klik ikon RequestFox untuk membuka panel samping (bilah sisi di Firefox) dan tekan Mulai Merekam, atau tekan Alt+Shift+S (Option+Shift+S di Mac). Pertama kali, browser meminta Anda mengizinkan akses ke situs tersebut: izinkan.

  4. Gunakan situs seperti biasa

    Klik alur yang sedang Anda uji. Setiap panggilan muncul begitu dimulai, terkait dengan klik atau pengiriman formulir yang memicunya. Agar panggilan paling awal sebuah halaman (login, konfigurasi, feature flag) tidak terlewat, centang “Muat ulang halaman untuk merekam panggilan awalnya” sebelum Anda menekan Mulai Merekam.

  5. Baca tandanya

    Panggilan yang gagal, lambat, terkirim dua kali, atau rusak di dalam 200 OK diberi tanda. Buka salah satunya untuk melihat header, body, waktu, dan alasannya dalam kata-kata sederhana.

  6. Hentikan, dan simpan buktinya

    Tekan Hentikan. Sesi disimpan di Riwayat untuk dibuka lagi dan dibandingkan. Dengan Ekspor, Anda menyimpannya sebagai laporan HTML, HAR, CSV, atau JSON, atau menyalin satu panggilan sebagai kode.

Menemukan satu panggilan dalam rekaman panjang

Ketik di kotak pencarian. Setiap kata harus cocok, dalam urutan apa pun, dan filter mempersempit daftar:

  • status:500 atau method:POST
  • host:api.example.com, atau -host:cdn.example.com untuk mengecualikan sebuah host
  • path:/users/:id untuk setiap panggilan ke satu endpoint, berapa pun id-nya

Jika tidak ada yang muncul

  • Daftar meminta Anda membuka situs dulu: Anda menekan “Mulai Merekam” di halaman browser. Buka situsnya, lalu tekan “Mulai Merekam”.
  • Anda memilih tidak mengizinkan akses: tekan “Mulai Merekam” lagi dan izinkan. Anda bisa mencabut akses itu nanti di pengaturan ekstensi di browser Anda.
  • Daftar kosong saat merekam: halaman belum membuat panggilan apa pun. Klik sesuatu yang memuat data, atau muat ulang halaman.
  • Pintasan tidak berfungsi: mungkin ekstensi lain memakainya. Atur lagi di chrome://extensions/shortcuts (Firefox: about:addons, ikon roda gigi, Kelola Pintasan Ekstensi).
