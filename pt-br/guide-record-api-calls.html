Como gravar as requisições HTTPS (chamadas de API) que um site faz

Para ver as chamadas de API que uma página faz, abra o DevTools do navegador, escolha Rede (Network) e filtre por Fetch/XHR (XHR no Firefox); não há nada para instalar. Para guardá-las, ter as problemáticas sinalizadas e poder repeti-las ou exportá-las, use uma extensão de navegador como o RequestFox: instale, abra o site, pressione “Iniciar gravação” (ou Alt Shift S) e use o site normalmente. Cada fetch, XMLHttpRequest, frame de WebSocket e evento enviado pelo servidor aparece na lista assim que começa.

Para o RequestFox 2.5.0, verificado em 19 de novembro de 2026.

Primeiro, o jeito nativo: o painel Rede do DevTools

Você não precisa de uma extensão para ver as chamadas de API de uma página. No Chrome, abra o DevTools (F12), escolha Rede (Network) e clique no filtro Fetch/XHR. Clique com o botão direito em uma requisição e escolha Copiar (Copy) para copiá-la como cURL ou como fetch, e marque Preserve log para manter as requisições entre carregamentos de página [1]. No Firefox, o Monitor de rede abre com Ctrl+Shift+E (Cmd+Opt+E no Mac) [2]; o botão XHR filtra a lista, e “Copiar como cURL” e “Copiar como Fetch” ficam no menu do botão direito [3].

O DevTools lista tudo ao vivo, mas deixa o julgamento com você, e a lista some quando você o fecha. O RequestFox acrescenta as sinalizações, o histórico e a exportação. RequestFox ou o painel Rede do DevTools.

Passos para gravar chamadas de API no Chrome ou no Firefox

  1. Instale o RequestFox

    Adicione pela Chrome Web Store ou pelos Complementos do Firefox. Não é preciso se cadastrar em nada.

  2. Abra o site que você quer testar

    Qualquer página web normal funciona. Páginas do próprio navegador, como a de extensões, uma nova aba ou a Web Store, não podem ser gravadas; o RequestFox avisa se você tentar.

  3. Pressione “Iniciar gravação”

    Clique no ícone do RequestFox para abrir o painel lateral (a barra lateral no Firefox) e pressione Iniciar gravação, ou pressione Alt+Shift+S (Option+Shift+S no Mac). Na primeira vez, o navegador pede que você permita o acesso ao site: permita.

  4. Use o site normalmente

    Percorra o fluxo que você está testando. Cada chamada aparece assim que começa, ligada ao clique ou ao envio de formulário que a causou. Para não perder as primeiras chamadas de uma página (login, configuração, feature flags), marque “Recarregar a página para gravar as chamadas iniciais” antes de pressionar Iniciar gravação.

  5. Leia as sinalizações

    Chamadas que falharam, foram lentas, saíram duas vezes ou quebraram dentro de um 200 OK ficam sinalizadas. Abra uma para ver os cabeçalhos, o corpo, os tempos e o motivo em palavras simples.

  6. Pare e guarde as evidências

    Pressione Parar. A sessão fica no Histórico para você reabrir e comparar. Com Exportar, você a salva como relatório HTML, HAR, CSV ou JSON, ou copia uma chamada como código.

Encontrar uma chamada em uma gravação longa

Digite na caixa de busca. Cada palavra precisa bater, em qualquer ordem, e os filtros restringem a lista:

  • status:500 ou method:POST
  • host:api.example.com, ou -host:cdn.example.com para deixar um host de fora
  • path:/users/:id para cada chamada a um mesmo endpoint, qualquer que seja o id

Se nada aparecer

  • A lista pede para abrir um site primeiro: você pressionou “Iniciar gravação” em uma página do navegador. Abra o site e pressione “Iniciar gravação”.
  • Você escolheu não permitir o acesso: pressione “Iniciar gravação” de novo e permita. Você pode remover o acesso depois, nas configurações da extensão no navegador.
  • A lista está vazia durante a gravação: a página ainda não fez nenhuma chamada. Clique em algo que carregue dados, ou recarregue a página.
  • O atalho não faz nada: outra extensão pode estar usando. Defina de novo em chrome://extensions/shortcuts (Firefox: about:addons, a engrenagem, Gerenciar atalhos de extensões).
