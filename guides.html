Keyboard shortcuts

Alt Shift S
Start or stop recording; opens the panel
Alt Shift M
Switch the panel to Full, Background or Mini
/
Jump to the search box
F6 (back: Shift F6)
Move to the next part of the panel: top bar, start bar, filters, calls, footer
Ctrl Enter (Mac: Cmd Enter)
Send from any Compose field
Ctrl S (Mac: Cmd S)
Save the request in Compose: changes go into the saved request; a new one opens Save to collection
Esc
Close a dialog or menu, or the open panel, and go back where you were
Enter in Compose's address
Send

On a Mac, Option+Shift instead of Alt+Shift. Help → Keyboard shortcuts lists them in the panel. Change the first two at chrome://extensions/shortcuts (Firefox: about:addons, the gear, Manage Extension Shortcuts).
